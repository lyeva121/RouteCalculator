# RouteCalculator (веб-версия)

Расчёт элементов полёта (МК и время по участкам) с учётом ветра. Работает в браузере на ПК, смартфонах и планшетах. Сборка не нужна: приложение — один файл `index.html`.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки (включая скрытые `.github` и `.nojekyll`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Перейдите на вкладку **Actions** и дождитесь зелёной галочки у запуска *Deploy to GitHub Pages* (запускается при каждой загрузке в ветку `main`).
4. Адрес приложения: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Установка на смартфон/планшет/ПК (PWA)
Откройте адрес приложения в браузере:
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone/iPad (Safari):** кнопка «Поделиться» → «На экран «Домой»».
- **ПК (Chrome/Edge):** значок установки в адресной строке.

После первого открытия с интернетом приложение работает без сети. Обновления подтягиваются при следующем запуске с интернетом (если нужно принудительно сбросить кэш — измените `CACHE` в `sw.js`, например на `route-calculator-v2`).

## Особенности веб-версии
- «PDF» создаёт файл в стиле настольной версии (A4, шрифт DejaVu Sans, таблица ППМ / S / МК / Время / Примечание, итоги и ветер по маршруту) и открывает его в новой вкладке. Если вкладка заблокирована, файл скачивается как `route.pdf`.
- «Сохранить» скачивает файл `route.json`, «Открыть» загружает его (совместим с файлами настольной версии).
- Данные хранятся только в браузере и никуда не отправляются.
- Иконки в папке `icons/` можно заменить своими (192×192, 512×512, maskable 512×512, apple-touch-icon 180×180) с теми же именами.
- Шрифт `fonts/DejaVuSans.ttf` распространяется по свободной лицензии (`fonts/LICENSE-DejaVu.txt`).
